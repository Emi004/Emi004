### 💻 Featured Repositories

* ⌨️ **[ajazz-rgb-cli](https://github.com/Emi004/ajazz_rgb_controller)**  
  A lightweight, open-source **Python CLI utility** published on PyPI designed to control the RGB lighting execution on the Ajazz AK820 Pro keyboard cross-platform. Developed as an alternative for Linux/Unix environments to bypass native Windows-only software constraints. Implements low-level raw USB communication parameters via customized `udev` interface rules, granular Hex color rendering transformations, automated environment path integration for dynamic systems scripting (e.g., Hyprland), and hardware flush mechanics to prevent payload buffer spamming.

* 🎵 **[Sonata (Live Music Streaming App)](https://github.com/Emi004/Sonata)**  
  A full-stack music streaming platform built with a **FastAPI** backend and a **React (TailwindCSS + DaisyUI)** frontend. Integrates **Supabase** for secure user authentication, session state tracking, database queries, and remote storage buckets (handling audio tracks and profile/album media assets). Features a multi-role user architecture (User, Artist, Admin) driving an adaptive dynamic sidebar, a robust audio player, debounced search filters, a dynamic main carousel for new releases, and an advanced media uploading workflow complete with real-time previews and draft saving capabilities. Fully automated using **GitHub Actions** for CI/CD, deploying the frontend to GitHub Pages and the backend services to Render.

* 🤖 **[Steam Games Analysis using NLP & ML](https://github.com/Emi004/Steam_Games_Data_Analysis)**  
  An end-to-end data science project utilizing the **Steam Web API** to analyze player behavior and ecosystem trends. Implemented Natural Language Processing (**TF-IDF, N-Gram analysis, POS tagging, and VADER Sentiment Analysis**) on user reviews and game descriptions. Built scalable preprocessing structures utilizing **PySpark / Pandas** and developed a supervised **Machine Learning (Scikit-Learn)** classification model to predict player refund decisions based on review characteristics, playtime statistics, and sentiment metadata.

* 🍕 **[snackApp (Full-Stack Recipe App)](https://github.com/Emi004/snackApp)**  
  A full-stack recipe management application featuring dynamic metric calculation based on servings. Built using **Python (Flask)** and **React**, backed by a **MySQL** database, containerized with **Docker**, and fully deployed live via **AWS**.
